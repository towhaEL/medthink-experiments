Sign in with browser

1In your browser, sign in to kaggle.com as the account you want to add.
2Click Start sign-in. A Kaggle consent page opens in that browser.
3Approve it. The account is saved in its own sandbox and tested.
Your current ~/.kaggle login is not touched. An account that is already added is refused.
Adding a second account? Start sign-in always uses the Kaggle user your browser is logged in to. Use Sign in with a link instead and open the link in a private window.
1Open the link in a private / incognito window (or another browser profile) and sign in as the account you want to add.
2Approve the consent page. Kaggle then shows a verification code.
3Paste the code below and click Finish. The link expires after 15 minutes.
